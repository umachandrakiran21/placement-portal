# Placement Portal

A simple full-stack Placement Portal project built using Node.js, Express.js, HTML, CSS, and JavaScript.

## 🚀 Features

* Add tasks
* Edit tasks
* Delete tasks
* Dynamic frontend updates
* REST API integration
* Full CRUD operations

---

## 🛠 Tech Stack

### Frontend

* HTML
* CSS
* JavaScript

### Backend

* Node.js

## ▶️ Run Project Locally

### 1. Clone Repository

```bash
git clone https://github.com/umachandrakiran21/placement-portal.git
```

### 2. Open Project

```bash
cd placement-portal
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Server

```bash
npm start
```

### 5. Open Browser

```text
http://localhost:5000
```

---

## 📌 API Endpoints

### GET Tasks

```http
GET /api/tasks
```

### Add Task

```http
POST /api/tasks
```

### Edit Task

```http
PUT /api/tasks/:id
```

### Delete Task

```http
DELETE /api/tasks/:id
```
